🔥 ENTROPY WEAVER

Prototype Strategy Report • March 18, 2026

🎯 Core Concept

A physics-manipulation puzzle game where players control the fundamental law of decay. Unlike traditional puzzle games with static obstacles, Entropy Weaver introduces dynamic state transitions that create emergent gameplay scenarios.

Unique Mechanics

  • Three-State System: STABLE → DECAYING → ENTROPIC → (regenerates entropy)
  • Resource Loop: Using entropy consumes charges, but letting things dissolve completely replenishes them
  • Reversibility: Unlike typical destruction mechanics, players can REVERSE entropy to rebuild paths
  • Strategic Timing: Decaying walls have a countdown - plan your route before they vanish

🎮 Engagement Loop

The "One More Try" Hook

  • Immediate Feedback: Visual particle effects, screen shake, and sound on every entropy action
  • Progressive Complexity: 8 levels with increasing maze complexity and strategic depth
  • Scoring System: Base score + entropy bonus + reverse bonus encourages efficiency
  • Badge System: Gold/Silver/Bronze mastery levels based on remaining resources

Session Design

  • Short Sessions: 2-5 minutes per level
  • No Punishment: Instant retry with full reset
  • Clear Win State: Portal entry triggers completion screen with stats
