Orbit Orchard — Strategy Report

Trend anchor: hypercasual-game. Positioning: a premium-feeling one-thumb catcher with combo tension, readable goals, and visible badge progression.

Core loop

Read instructions instantly → move skiff → catch starfruit → chain streaks → dodge void pods → upgrade badge every 5 catches → hit 1200 before dusk.

The loop is built for low-friction retries: immediate start, obvious failure sources, and a strong score chase.
