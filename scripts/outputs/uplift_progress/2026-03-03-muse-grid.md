Genre implemented: **Puzzle Logic Grid** (original concept: *Cipher Couriers*).

## What was rebuilt
- Full game redesign around deduction from logic clues (not reflex/minigame loop).
- Unique-case generator using two hidden bijections:
  - Detective -> Artifact
  - Detective -> Room
- Clue system with positives/negatives (`DA`, `DR`, `AR`, `nDA`, `nDR`, `nAR`).
- Brute-force solver over all mapping candidates to enforce uniqueness.
- Round flow (8 cases), 3 lives, 40s timer per case.
- Immediate answer feedback (`Correct +points` or `Wrong + correct answer`).
- Explicit outcomes:
  - **Win:** solve all 8
  - **Lose:** lives reach 0 / timeout depletion
- Score, streak, timer bar, reward tiers:
  - Apprentice / Sharp Sleuth / Grid Virtuoso / Grand Logician
- In-game instructions + hint + built-in QA simulator button.

## Iteration notes
