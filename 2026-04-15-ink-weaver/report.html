🎯 Core Loop Explanation

The Creative Physics Hook: Players draw shapes that transform into physics objects (platforms, bouncy balls, float orbs, gears) to solve physics puzzles. The core loop combines creativity with iterative problem-solving.

Loop Breakdown:

  • Assessment Phase: Analyze level layout - orb start, star goal, obstacles
  • Design Phase: Select ink type and draw solution path
  • Test Phase: Activate physics simulation to test creation
  • Iterate Phase: Observe failure points, clear and redesign
  • Success Phase: Orb reaches star, earn stars based on efficiency
  • Progression: Unlock new ink types, face complex multi-tool challenges

Ink Types & Mechanics:

⬛Solid Ink - Static platforms 🏐Bouncy Balls - High elasticity 🎈Float Orbs - Upward buoyancy ⚙️Gear Wheels - Rotating pushers

Engagement Mechanics:

  • Multiple Solutions: Every level has infinite possible solutions
  • Efficiency Scoring: Stars based on ink used + attempts (speedrun potential)
  • Creative Expression: Players can draw artistic solutions, not just functional
  • Low Friction Retry: One-click reset, instant physics toggle
  • Gradual Complexity: 8 levels introducing tools progressively
  • Satisfying Physics: Realistic collisions, bounces, and momentum

⚠️ Risk Assessment

HIGH RISK: Input Precision on Mobile

Drawing physics requires precision that may frustrate mobile users with fat fingers.

Mitigation: Implement line smoothing, undo (3 levels), zoom/pan mode. Market primarily to tablet users. Desktop web version for precision.

MEDIUM RISK: Solution Frustration

Players may get stuck and quit without hints. Open-ended puzzles can cause analysis paralysis.

Mitigation: Optional hint system after 3 failed attempts. "Show Community Solutions" button. Skip level (with star penalty).

MEDIUM RISK: Physics Simulation Inconsistency

Floating point physics can cause "lucky" solutions that work inconsistently, frustrating players.

Mitigation: Deterministic physics engine (fixed timestep). Replay validation. "Verified Solution" badge for consistent solves.

LOW RISK: Content Saturation

8 levels may feel short, though UGC extends content infinitely.

Mitigation: Level editor unlocks at level 5. Daily challenges. Community level curation. Plan 20+ official levels at launch.

LOW RISK: Cloning by Competitors

Simple mechanic is easy to clone, limited moat.

Mitigation: Build brand through art style (unique ink aesthetic). Community features create network effect. Continuous content updates.
