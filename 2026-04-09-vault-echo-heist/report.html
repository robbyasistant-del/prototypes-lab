Vault Echo Heist — Report

Prototype date: 2026-04-09

VALIDATION

Checked:

  • index.html exists and runs as a self-contained playable build
  • instructions are visible instantly before the first interaction
  • loop includes scouting, action budget, score, rewards / badges, explicit win and game-over outcomes, and immediate feedback to every open/mark action
  • mechanic is distinct from memory-match templates: this is a memory-bluff extraction game with echo markers, decoys, and exact-target pressure

Concept

A stylish micro-heist where memory is only the opening move. The real game is deciding what to mark, what to ignore, and when to extract before the vault fully wakes. It turns a short memorization phase into a higher-tension bluff-and-risk puzzle.

Why it can hook

The run starts instantly, the stakes are obvious, and losses feel personal: I knew that trap was bottom-left. Exact-loadout pressure creates sharp, replayable optimization without needing long sessions.

Strategy

Position it as Ocean's Eleven meets a five-second memory test. Strong daily potential because one seed can be shared socially, but the endless arcade version can still drive session depth.

Creatives should show the dramatic scout countdown, map blackout, then a clean last-second extraction.

Core loop

  1. Scout the grid for 5 seconds.
  2. Plant echo / decoy tools.
  3. Raid high-confidence tiles.
  4. Balance relic precision against alarm growth.
  5. Extract for a win or trip a clean game over.

Rewards

Score, exact-loadout pride, performance badges, and the fantasy of being a slick thief rather than a passive memory-tester.

KPIs

  • average runs per user session
  • perfect extraction rate
  • alarm-at-extraction median
  • tool usage rate (echo / decoy)
  • restart rate within 10 seconds of a fail

Experiments

  • Add rotating guard sweeps after scout phase
  • Daily named vaults with seeded target sets
  • Prestige mode with fewer tools
  • Social share card for lowest-alarm win

Risks

  • If scout duration is too short, game feels unfair
  • If too long, tension collapses
  • Need broader content set for long-term mode variety
