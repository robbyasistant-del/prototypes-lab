🎯 Strategy

"Tension Management" Genre Positioning

CoreMelt occupies a unique space between resource management sims and survival games, creating a sub-genre we're calling "Tension Management".

Unlike traditional resource management games that focus on efficiency optimization, or survival games that emphasize exploration, CoreMelt delivers intense, time-pressured decision-making where every choice has cascading consequences.

Target Audience

  • Casual Hardcore: Players who want depth without 100-hour time investments
  • Speedrun Enthusiasts: Perfect for score-attack optimization
  • RTS/FPS Players: Appeals to APM (actions-per-minute) skill expression
  • Mobile-First: Quick session length (60-120 seconds) ideal for mobile

Unique Selling Proposition

"The Dark Souls of resource management." - Every run teaches you something. Death is expected, improvement is visible, mastery is earned.

Score Multipliers

  • Base Score: Seconds survived × 10
  • Efficiency Bonus: Based on average gauge health (0-100%)
  • Rank Multiplier: Higher ranks = higher score potential
  • Perfect Run: 0 breaches = 2x multiplier

Session-Level Rewards

  • Survival Badges: Bronze/Silver/Gold based on 60s performance
  • Close Call Bonus: Surviving with <10% on any gauge
  • Efficiency Master: Maintaining all gauges in green for 30s+
  • Event Survivor: Handling 5+ events without breach

🧪 A/B Testing Plan

Test 1: Event Frequency

Events force adaptation and create tension, but too frequent feels unfair.

Variant A: Conservative

Events every 15-25 seconds

Hypothesis: Lower frequency allows more strategic play, higher completion rate

Variant B: Aggressive

Events every 8-15 seconds

Hypothesis: Higher tension drives more retries and "one more run" feeling

Success Metric: Compare retry rates and session counts between variants.

Test 2: Starting Difficulty

First impression matters. Starting too hard causes early churn.

Variant A: Gentle Start

Demand starts at 20%, first event at 20s

+5 second "grace period" before any gauge can breach

Variant B: Immediate Pressure

Demand starts at 35%, first event at 10s

No grace period - immediate skill check

Success Metric: D1 retention and second-session rate.

Test 3: Visual Feedback Intensity

Variant A: Subtle

Minimal screen effects, gentle pulse on critical

Audio warnings only at extreme values

Variant B: Dramatic

Full screen shake, red flash, intense pulsing

Escalating audio beeps starting at yellow zones

Success Metric: Average survival time and subjective "excitement" ratings from playtest surveys.

Test 4: Breach Recovery

Variant A: Forgiving

After breach, gauges reset to safe values

5-second immunity from further breaches

Variant B: Punishing

Gauges stay at breach values

No immunity - chain breaches possible

Success Metric: 3rd breach timing and "unfair" feedback from users.

⚠️ Risk Assessment

🎲 CRITICAL: Randomness vs Skill Expression

The biggest risk to CoreMelt's success is the perception of randomness. If players feel events are arbitrary or unavoidable, the "git gud" motivation disappears. This destroys the core value proposition.

Mitigation Strategies:
  • Event Warning System: 2-second telegraph before events activate (visual + audio)
  • Predictable Event Types: Each event type always has the same effect - players learn patterns
  • Counter-Play: Every event has an optimal response (e.g., Coolant Leak → prepare Vent)
  • "Perfect Play" Possible: Theory-craft: skilled player can handle any event combination
  • Replays: Show what caused death with clear "You died because X" messaging
📉 MAJOR: Session Length Fatigue

60 seconds is the target, but players may expect variety sooner. Repeating the same loop without new elements could cause boredom after 10-15 sessions.

Mitigation Strategies:
  • Shift Variations: Each "rank up" introduces slight rule changes (e.g., faster demand growth)
  • Daily Challenges: Special conditions ("No Coolant", "Double Events") for variety
  • Unlockable Cores: Different reactor types with unique gauge interactions
  • Leaderboards: Social competition extends engagement indefinitely
🎨 MODERATE: Visual Clarity

Three moving gauges + events + controls + reactor core = visual overload. Players may miss critical information in the noise.

Mitigation Strategies:
  • Priority Color Coding: Most critical gauge pulses/prominent
  • Audio Hierarchy: Different warning tones for each gauge type
  • Simplify Mode: Optional setting for high-contrast, minimal UI
  • Playtest Eye-Tracking: Verify where attention goes during crisis moments
💰 LOW: Monetization Fit

Tension-based gameplay may not naturally accommodate ads or IAP without breaking immersion.

Mitigation Strategies:
  • Continue System: Watch ad to continue run (1 per run, breaks tension appropriately)
  • Cosmetic Cores: Premium reactor visual themes (no gameplay impact)
  • Remove Ads: One-time purchase for premium experience
  • Battle Pass: Seasonal rank progression with cosmetic rewards
