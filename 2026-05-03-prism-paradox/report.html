Prism Paradox — Strategy Report

Trend basis

Built from browser casual + brain teaser signals. This prototype leans into visual elegance and crisp “aha” routing moments instead of cloneable match-three behavior.

Core loop

  • Read the chamber instantly.
  • Rotate mirrors under a clear budget.
  • Fire the beam and watch the route.
  • Clear chambers and chase efficient solves.
  • Retry after overload because feedback is immediate and legible.

Rewards / badges

  • Rotation-left bonus rewards optimization
  • Clear streak badge creates medium-term mastery
  • Explicit win/loss keeps sessions tight

SEO / ASO / SEM

  • SEO: laser puzzle game, mirror maze browser, crystal logic game
  • ASO: “rotate mirrors, fire light, solve chambers”
  • SEM: test calm-logic creatives vs neon-beam spectacle creatives

KPIs

  • Beam fires per chamber
  • Chamber clear rate
  • Average rotations remaining
  • Retry rate after overload
  • Win rate on chamber 5

Experiments

  • Daily chamber seed
  • Touch drag mirror controls
  • Three-target expert layouts
  • Ghost solution replay

Risks

  • More level variety will be needed for longer retention.
  • Difficulty curve should be telemetry-tuned.
  • Future version could add richer beam color mixing.
