Helix Fall — Mechanic Correction Report

Play the updated prototype

What was corrected

This pass fixes the core interaction to better match the original Helix Jump loop: blue/safe slices stop the fall and bounce the ball modestly, while only a true gap allows the ball to keep falling, clear the level, and score.

What changed in r10 mechanic-match

  • Centered ball / rotating tower remains the interaction model.
  • Stable safe collision snaps the ball onto blue slices and rebounds it instead of letting it slip through.
  • Gap clear scoring now happens when the player actually passes a platform through its opening.
  • Platform break feedback throws ring shards when a row is cleared.
  • Removed bounce scoring so points track actual clears rather than ordinary waiting bounces.
  • Visible version bump to v2026.03.26-r10 mechanic-match.

Reference note

Web search tooling was unavailable during this pass, so the correction was based on established knowledge of Helix Jump’s platform loop: safe platform = catch + small bounce, gap = pass + break + score, danger = fail.

Verification target

Local verification should confirm: no blue-platform tunneling, no repeated false collision spam, readable small bounce on safe contact, visible break feedback on gap clears, and the mirrored docs files matching the prototype files.
