Helix Fall Rebuilt — Rebuild Report

Play the rebuilt prototype

Why this rebuild happened

The previous version failed at the basics: the player ball was not reading clearly, platforms and shaft geometry were easy to lose, visual feedback was weak, and mobile controls did not feel trustworthy. This rebuild throws away the “subtle” presentation and prioritizes readability and playability first.

What changed in rebuild r4

  • Oversized glowing player orb with highlight, shadow, bounce squash, and particle bursts.
  • Thick central shaft with strong edge rails so the playable lane is always obvious.
  • Chunky platforms using bright cyan safe zones, dark bordered gaps, and hot red death strips.
  • Usable controls with hold-to-move desktop keys and large mobile buttons.
  • Clear mechanics loop: fall through dark gaps for streak/score, bounce on safe platforms, die on red.
  • Immediate feedback via flashes, shake, streak growth, particles, and readable HUD state.
  • Visible version bump to v2026.03.25-r4 rebuild for remote testing.

Design intent

This is still a 2D Helix Jump-inspired vertical-fall game, but it now behaves like a testable action toy rather than a vague mockup. Every important object is high-contrast and oversized on purpose. The rebuild favors a clear first-play experience over minimalism.

Local verification target

Before shipping, the rebuild should be opened locally and checked for: visible ball at spawn, readable shaft/platforms, responsive left/right controls, bounce feedback on cyan landings, red death behavior, and mirrored docs copies matching the prototype.
