Threadline

Prototype Report — May 13, 2026

🎯 Strategy

Concept: A tactile memory & pattern game with a textile/weaving aesthetic. Players watch colored threads animate across a loom grid, then must recreate the exact pattern by drawing lines in the correct order, direction, and color. The "crossing memory" mechanic — remembering which thread passes over which — adds a unique spatial layer absent from typical memory games.

Target Audience

Players who enjoy meditative, skill-based puzzle games:

  • Fans of Monument Valley, Alto's Odyssey (aesthetic appeal)
  • Memory game players (Simon, Lumosity users)
  • Casual players seeking "brain training" with style
  • Strong appeal to 25-55 female demographic (craft aesthetic)

Monetization Potential

  • Premium unlock: $2.99 for "Master Weaver" — removes ads, unlocks all 100 levels
  • Thread packs: $0.99 cosmetic thread themes (silk, neon, gold, holographic)
  • Loom skins: $1.99 backgrounds (Japanese tatami, Moroccan tile, Scandinavian wood)
  • Hint system: Watch rewarded video for 3-second replay of target thread
  • Daily weave: One special pattern per day with global accuracy leaderboard

🔄 Core Loop

LOAD LEVEL
    ↓
MEMORIZE PHASE (3-8 seconds)
    └─ Threads animate across loom in sequence
    └─ Player watches paths, colors, crossing order
    ↓
RECALL PHASE
    └─ Loom clears to grid only
    └─ Player draws Thread 1 → then Thread 2 → etc.
    └─ Must match path, color, AND entry point exactly
    ↓
VALIDATION (per thread)
    ├─ CORRECT → Thread locks in place → Pleasant chime → Next thread
    ├─ WRONG → Thread snaps → Lose 1 life → Retry same thread
    ↓
ALL THREADS CORRECT → LEVEL COMPLETE → Badges → Next Level
         │
         └─ 3 LIVES LOST → GAME OVER → Share score → Retry

Session target: 5-10 minutes for 10-level run. Individual level: 20-50 seconds.

📋 Build Notes

  • Single-file HTML5 prototype using Canvas 2D API
  • No external dependencies — loads instantly anywhere
  • 5x5 to 8x8 grid scaling across 10 levels
  • Memorize phase with animated thread drawing
  • Recall phase with touch/mouse path drawing (snap-to-grid)
  • 3-star badge system with par times per level
  • Wooden loom aesthetic with warm palette
