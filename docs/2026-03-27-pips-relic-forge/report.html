Pips Relic Forge — strategy report

Genre: Dice crafting puzzle
Signal: Pips/daily puzzle durability + collection mastery + exact-match bragging
Date: 2026-03-27

Core loop

  • See goal instantly in first screen.
  • Take one low-friction action immediately.
  • Get feedback, score, and chain reward on every turn.
  • Push toward clear win condition while managing fail pressure.

Why this concept

Built to chase current clean trend signals: durable daily-puzzle appetite, seasonal prank energy, and high-retention mastery loops. The prototype avoids cloning prior catalog mechanics by centering its own verb set and reward framing.

SEO / ASO / SEM

  • SEO angle: skill-based puzzle, streak, tips, walkthrough, daily mastery.
  • ASO hooks: “satisfying”, “brainy”, “quick rounds”, “one more try”.
  • SEM tests: creative A/B on “Can you survive 90 seconds?”, “5 relics before meltdown”, “Save the gala before suspicion hits 100”.

Rewards & retention

  • Score growth + streaks create immediate compulsion.
  • Named badges add collectible goals even in single-session prototype form.
  • Win/lose states support replay and measurable session success.

KPIs

  • First-action-under-10s rate
  • Average rounds per user
  • Win rate between 25% and 45%
  • Median best-score improvement over first 3 sessions
  • Badge unlock rate

Experiments

  • Difficulty ramp softness in first minute / first three turns
  • Daily challenge seed
  • Meta-progression with cosmetic unlocks
  • Leaderboard and share card

Risks

  • If balance is too soft, replay desire drops.
  • If balance is too punishing early, first-session retention suffers.
  • Future expansion should preserve the readable, polished visual style rather than overloading the screen.
