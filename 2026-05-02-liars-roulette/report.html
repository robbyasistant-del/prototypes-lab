🎭 Liar's Roulette

2026-05-02 | Social Deduction Speed Game | Strategy Report

🎯 Core Concept

A fast-paced social deduction game where you play against 5 AI suspects. Each round, one suspect makes a statement — but some are liars with visual tells. You have exactly 3 seconds to detect the deception. Streaks multiply your score. A genuinely original take on social deduction for single-player browser play.

🎮 Gameplay Loop

  • 5 AI characters are seated around a virtual table
  • Each round, one random character speaks a statement
  • Visual tells appear if the character is lying (sweating, nervous ticks, shifting eyes)
  • Player calls TRUTH or LIE within 3 seconds
  • Correct calls build streaks → score multipliers
  • 3 wrong calls = GAME OVER | 20 correct = WIN

🧠 Unique Mechanics

Character Profiles with Lie Rates

Each AI has a unique liar rate (Vince: 60%, Luna: 30%, Kato: 70%). Learning each character's baseline deception probability is key to mastery.

Visual Tell System

When lying, characters exhibit animated tells: sweating (💧 pulsing), nervous (😰 scaling), shifting eyes (👀 text animation). These are subtle but learnable patterns.

3-Second Pressure Timer

The timer bar shrinks rapidly from purple to red. Timeouts count as wrong answers, forcing snap decisions under pressure.

Streak Multiplier System

Every 5 consecutive correct calls activate a multiplier tier. 5 streak = x2, 10 streak = x3. This creates intense "don't break the streak" tension.
