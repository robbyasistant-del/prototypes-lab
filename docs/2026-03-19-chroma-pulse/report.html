CHROMA PULSE

Synesthetic Rhythm Action Game - Strategy Report

🎮 Game Concept & Hook

CHROMA PULSE merges rhythm game mechanics with color-matching reflex challenges in a synesthetic audio-visual experience. The core innovation is the "Color-State" system where players must match their central orb's color to incoming rings.

The Hook: Unlike typical rhythm games with fixed note highways, CHROMA PULSE features a 360-degree radial playfield where color-matching is the key mechanic. The "one more try" factor comes from the satisfying color-transition animation and escalating combo multipliers.

🔄 Core Loop Explanation

  • 1. Anticipation: Colored rings spawn at screen edges and travel inward
  • 2. Decision: Player must judge if current orb color matches incoming ring
  • 3. Action: Click/tap to pulse when ring enters the hit zone (40-140px radius)
  • 4. Feedback: Immediate visual explosion, combo counter, score pop-up
  • 5. Escalation: Rings spawn faster as score increases (beatInterval decreases)
  • 6. Risk/Reward: Wrong color = health loss; Perfect timing = combo multiplier

Retention Mechanics

  • Combo System: 10% score multiplier per combo level
  • Badge Collection: 4 unlockable badges per run
  • Health Tension: Single mistake doesn't end run, creates "clutch" moments
  • Win State: 10,000 point goal gives clear objective
