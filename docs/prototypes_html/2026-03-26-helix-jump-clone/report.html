Helix Jump Clone — Sprint 1 Report

Play the prototype

What this build delivers

  • Centered ball with camera anchored to the ball and the tower scrolling around it.
  • Swipe / drag rotation with touch, mouse, and keyboard fallback.
  • Initial safe-row bounce loop so the run starts alive before the player opens a gap.
  • Deterministic swept crossed-row detection: every row crossed during downward travel is checked in order.
  • Safe-platform bounce, squash/stretch, combo reset to x1.
  • Gap clears shatter the row, score points, play reward tones, and raise the combo for consecutive clears.
  • Reworked faux-3D tower rendering with a thicker pillar and one continuous sealed solid segment per row instead of fragmented arc pieces.

Visual readability pass

  • The center pillar is intentionally thicker so the structure reads as a cylinder instead of a thin post.
  • Each row now uses one continuous safe platform segment, so the visible floor reads as a sealed solid instead of several adjacent strips.
  • Front-facing platform faces still use stronger top/side separation, while rear arcs stay lighter and flatter so depth is easier to parse.
  • Gap boundaries keep explicit radial side faces, but the platform body is no longer split into multiple independent polygon pieces.

Controls

Drag or swipe left/right anywhere on screen to rotate the tower. Keyboard fallback: ← → or A D. Press R or use the restart button to reset the run.

Scoring and combo

Each cleared row awards 10 × current combo. The first clear after a bounce is x1; consecutive clears without touching a platform increase the multiplier to x2, x3, and beyond. Any safe bounce resets the chain back to x1.

Known limits for next sprint

  • No fail-state/danger slices yet; this sprint stays focused on core descent feel.
  • Row generation is fair and varied, but difficulty ramp and special rows can be expanded.
  • Audio uses lightweight Web Audio tones instead of authored SFX assets.
