Lumen Echo — Drift Memory

Memory game with spatial transform: remember a beacon sequence, then replay it on a shifted map.

How it works: In each round, beacons flash in order on the 5×5 map (observe phase).
Then the map applies a drift transform (rotate / mirror / shift), and you must click the transformed positions in the same order.
Scoring: +100 base per correct click + speed bonus + round-clear bonus. Wrong click costs 1 Stability.
Win: clear Round 8. Lose: Stability reaches 0 or timer expires. Badge at end: 🏅 Prism Oracle (9000+) / 🥈 Echo Pilot (6000+) / 🛰️ Cadet.
