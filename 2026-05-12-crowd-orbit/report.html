Crowd Orbit - Strategy Report

Date: 2026-05-12 | Folder: 2026-05-12-crowd-orbit

Concept summary
A category-slinging orbital defense game where you fling opinion pods into the right ring before the arena jams. Trend basis: Connections-style grouping plus social-content chaos.

Trend signal / market rationale

Connections-like grouping remains sticky, but social trend signals suggest louder, more theatrical packaging performs well. This turns categorization into a moving orbital target game.

Core loop

Read a pod instantly, fire it into the matching orbit ring, and manage growing speed as the crowd meter climbs.

Rewards & progression

  • Instructions are visible immediately on load.
  • Every action returns score and state feedback.
  • Badges unlock mid-run to create motivation spikes.
  • Explicit win and game-over states close the loop cleanly.

SEO / ASO / SEM angles

  • category game browser
  • connections inspired arcade game
  • social trivia html5 game
  • orbital sorting game

ASO positioning: emphasize instant comprehension, strong first-session visuals, and score-chasing repeatability.

SEM hypothesis: target browser puzzle / fast challenge / arcade word / category sorter intents, then retarget with beat-your-best creative.

KPIs to watch

  • correct ring accuracy
  • late-wave churn
  • streak milestone rate
  • miss-to-retry conversion

Experiments next

  • theme packs from daily trends
  • boss pods with double categories
  • same-device versus mode

Risks

  • readability under motion is critical
  • too much late-game speed could hurt fair feel

Production note

Prototype is intentionally self-contained in a single HTML file for quick deployment to GitHub Pages. Next hardening pass: analytics hooks, accessibility labels, daily content seeding, and mobile tuning.
