Prism Core

Prototype Report — May 13, 2026

🎯 Strategy

Concept: A real-time color-mixing defense game where players rotate three orbital prisms (RGB) to match incoming enemy colors. Where beams overlap, they mix into secondary colors. This creates a unique spatial puzzle layered onto action gameplay — players must think in both position AND color theory simultaneously.

Target Audience

Puzzle-action fans aged 16-40. Cross-appeal to:

  • Tower defense players (positioning strategy)
  • Puzzle fans (color mixing logic)
  • Casual arcade players (quick sessions, high score chasing)

Monetization Potential

  • Cosmetics: Prism shapes, beam effects, core skins, background nebulas ($0.99-$4.99)
  • Boosts: Slow-mo for 5s, auto-aim assistant, shield bubble (rewarded video or soft currency)
  • Battle Pass: "Spectrum Seasons" with 50 tiers of cosmetics + currency
  • Remove Ads: $3.99 with exclusive "Pure Light" core skin

🔄 Core Loop

START WAVE
    ↓
ENEMIES SPAWN from screen edges (colored shapes approaching core)
    ↓
ROTATE PRISMS to aim beams at enemies
    ↓
OVERLAP BEAMS to mix colors when needed (Yellow/Magenta/Cyan/White enemies)
    ↓
CORRECT MATCH → Enemy destroyed → Score + Combo buildup
    ↓
WRONG MATCH → Enemy resists → Speeds up → Risk to core
    ↓
ALL ENEMIES DEFEATED + CORE ALIVE → WAVE COMPLETE → Badges → Next Wave
         │
         └─CORE DESTROYED → GAME OVER → Share score → Retry

Session target: 4-8 minutes for full 10-wave run. Individual wave: 20-60 seconds.

⚠️ Risks & Mitigations

RiskLevelMitigation
Color mixing too complex for casual playersHIGHExtended tutorial (3 interactive steps). Color wheel always visible. "Assist mode" highlights correct prism.
Multi-touch conflicts on mobileHIGHSimplify to single-drag orbit rotation as default. Individual prism drag as "advanced" option.
Difficulty spike at white/black enemiesMEDIntroduce new enemy types in isolated tutorial waves first. Allow difficulty selection (Casual/Normal/Hard).
Visual clutter with many beams/enemiesMEDDynamic beam opacity. Enemy health bars only on damage. Screen-space UI to declutter.
Colorblind accessibilityMEDImplement shape+symbol system (enemies have unique shapes AND colors). "Colorblind mode" with high-contrast patterns.

📋 Build Notes

  • Single-file HTML5 prototype using Canvas 2D with 'lighter' composite for beam blending
  • 3 orbital prisms with drag + keyboard rotation controls
  • 8 enemy types (R,G,B,Y,M,C,W,K) with unique shapes for accessibility
  • 10 waves with progressive difficulty scaling
  • Combo system, accuracy tracking, 3-tier badge system
  • Screen shake, hit flash, particle explosions for feedback
